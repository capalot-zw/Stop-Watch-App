# Stopwatch App

A simple, functional stopwatch app with lap tracking built with Capacitor.

## Download
- **APK**: [stopwatch-app.debug.v1.0.0.apk](./stopwatch-app.debug.v1.0.0.apk)

## Features
- Start / Stop / Reset
- Lap timing with history
- Millisecond precision

## Build from source
1. Unzip the source code
2. Run `npm install`
3. Run `npx cap sync`
4. Run `npx cap open android`

## Tech stack
- HTML/CSS/JS
- Capacitor
- Built entirely on mobile (Termux + Acode)
